# 블루 알마낙 한국어 패치 v0.9.0-rc1

Mega Drive 일본판 **블루 알마낙(Blue Almanac)**의 한국어 패치입니다. 현재 버전은 **v0.9.0-rc1 시험판**입니다.

**[패치 다운로드(v0.9.0-rc1)](https://github.com/kilk96/blue-almanac-korean-patch/releases/tag/v0.9.0-rc1)**에서 `BlueAlmanac_ko_v0.9.0-rc1.zip`을 받아 압축을 풀어 주세요.

엔딩까지의 플레이를 확인했으며, 이후 인트로·이름 입력·상태창을 보완하고 해당 기능을 추가 검증했습니다. 모든 선택지와 특수 상황을 확인한 것은 아니므로, 남은 문제는 제보를 받아 보완할 예정입니다.

## 포함된 변경

- 본문 대사 690개와 주요 메뉴·아이템·전투·시스템 문구 한글화.
- 인트로 세로 내레이션 19페이지 한글화와 전용 글꼴 적용.
- 이름 입력 한글 100자 가나다순 배치. 영문 대문자·숫자 지원, 최대 4글자.
- 상태창 첫 표시와 캐릭터 교대 시 출력 속도 개선.

## 지원 원본

| 항목 | 값 |
|---|---|
| 기종/리전 | Mega Drive / 일본판(J) |
| 형식 | 헤더 없는 raw BIN(압축 파일·인터리브 SMD 제외) |
| 원본 크기 | 1,048,576바이트 |
| 원본 SHA-256 | `F9A79BDC4F5BE9AD5D7C584980DE665F68137F97647D3CA5A983874387438BBE` |
| 결과 크기 | 2,097,152바이트 |
| 결과 SHA-256 | `6AD8FA2B25B72CDDDCE7CFF67613C01A9FDE7DBB1F8885F21511A37F0BF6F552` |

파일명은 달라도 되지만 크기와 SHA-256이 일치해야 합니다. 원본 ROM과 패치 적용이 끝난 ROM은 제공하지 않습니다.

## 적용 방법

1. 원본 ROM과 세이브를 백업합니다.
2. ZIP을 풀고 **xdelta3 3.2 호환 디코더**로 `BlueAlmanac_ko_v0.9.0-rc1.xdelta`를 원본에 적용합니다. 원본 검증 옵션을 끄지 않습니다.
3. 결과를 새 BIN 파일로 저장하고 위 결과 SHA-256과 비교합니다.
4. 에뮬레이터에서 결과 파일을 새로 실행합니다.

현재 폴더에 xdelta3.exe가 있는 경우의 명령 예시:

```powershell
Get-FileHash -Algorithm SHA256 '.\BLUEARMA.bin'
.\xdelta3.exe -d -s '.\BLUEARMA.bin' '.\BlueAlmanac_ko_v0.9.0-rc1.xdelta' '.\BlueAlmanac_ko.bin'
Get-FileHash -Algorithm SHA256 '.\BlueAlmanac_ko.bin'
```

xdelta3 3.2.0의 원본·결과 검증을 포함한 기본 armor 형식입니다. 구형 도구에서 적용되지 않을 수 있습니다. 패치 해시는 `SHA256SUMS.txt`를 참고하세요.

## 실행과 저장

검증 환경은 **BizHawk 2.11.1 / Genplus-gx**입니다. 실제 기기와 다른 에뮬레이터의 호환성은 확인하지 않았습니다. 테스트용 치트나 세이브는 동봉하지 않습니다.

기존 한국어 시험판의 이름 코드와 게임 내 저장 형식은 유지했습니다. 에뮬레이터의 상태 세이브는 실행 중 메모리까지 저장하므로, 버전을 바꾼 뒤에는 **새로 부팅하고 게임 내 저장으로 이어 하기**를 권합니다. 기존 세이브는 먼저 백업해 주세요. 한국어 이름이 있는 세이브를 일본어 원본에서 열면 이름이 다르게 표시될 수 있습니다.

## 알려진 제한

- 한글 이름은 선택표의 100자만 사용할 수 있으며 공백 입력은 지원하지 않습니다.
- 상태창은 기존 한국어 시험판보다 빨라졌지만 원본 게임보다 표시가 느린 경우가 있습니다.
- 일부 드문 상황의 메시지는 실제 사용 경로가 확인되지 않았습니다. 모든 특수 메시지의 번역·표시가 검증된 상태는 아닙니다.
- 현재 플레이 확인한 대사 배치를 유지했습니다. 줄바꿈이나 문장부호 간격 등에서 미처 확인하지 못한 문제가 남아 있을 수 있습니다.

## 검증과 제보

엔딩 플레이 확인 이후 수정한 기능은 해당 화면과 관련 동작을 중심으로 검증했습니다. 최신 버전 전체를 처음부터 엔딩까지 다시 플레이한 것은 아닙니다. 패치 적용 결과가 검증한 빌드와 같은지, 잘못된 원본을 거부하는지 확인했습니다.

문제를 제보할 때는 다음 정보를 함께 적어 주세요.

- 패치 버전과 에뮬레이터·코어 버전.
- 발생 장소, 대화 상대 또는 메뉴, 직전 조작.
- 실제로 표시된 문구와 문제 화면.
- 같은 문제가 다시 발생하는지 여부.

원본·완성 ROM은 첨부하지 마세요.
